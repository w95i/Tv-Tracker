Check badge

  • Dark circle, amber check. The ink circle (28px, 34px on the hero) pops in on a spring, then the amber check draws on. It gives the moment a clear "stamp", matching the Figma file.
  • Contrast. Ink #1C1400 on amber is about 11.5:1. The amber check on ink matches it.
  • Watching now has shows watched in the last N days (default 30). The most recent is the hero.
  • Been a while has shows with no progress for N+ days. Sort with the chip.
  • +N is the number of aired episodes left after the current one. At 0 it shows FINALE if the series has ended, or LATEST if it's still running.
  • Last episode: ALL CAUGHT UP if the show is still running (no confetti), SERIES COMPLETE if it has ended (with confetti and "N episodes watched"). The show then leaves the list.
  • A show from Been a while that you watch becomes the hero, and both counts update.
  • Input is locked while a card animates, so double taps can't mark two episodes.
  • Upcoming groups: Today · This week (1–7 days) · This month (8–31) · Later (32+).
  • List / Grid: one amber icon on a slim row under the tabs (there is no logo bar; notifications need a new home) (it shows the view you will switch to). It changes the page whose tab is selected; each page remembers its own choice, and the icon updates when you swipe. Each page remembers its own choice. Grid shows 3 posters per row with no hero, so about 9 shows fit on one screen.
  • Grid tile: season/episode on the poster, ✓ bottom-right (44px touch area), FINALE or LATEST tag on the last aired episode, amber bar = episodes watched ÷ episodes aired. Upcoming tiles show a countdown (TODAY in amber) and a PREMIERE or FINALE tag. In grid view Upcoming is one continuous grid, soonest first (no date groups: the countdown already says when, and groups would leave half-empty rows).
